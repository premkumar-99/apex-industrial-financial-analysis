# Apex Industrial Technologies — Financial Analysis & Valuation

## 📊 Project Overview

This is a financial analysis and valuation project built using **Microsoft Excel** for a fictional industrial company, Apex Industrial Technologies.

The project focuses on understanding the company's historical financial performance, forecasting future results, analyzing business risks, and estimating intrinsic value using a **DCF valuation model**.

AI was also used to enhance the presentation of the Excel-based analysis into professional visual content for communication and LinkedIn.

> **Note:** Apex Industrial Technologies and the financial data used in this project are fictional and created for learning and portfolio purposes.

---

## 🎯 Objectives

- Analyze historical financial performance
- Evaluate revenue and EBITDA growth
- Analyze profitability and margins
- Review working capital and cash flow
- Analyze debt and leverage
- Build financial forecasts
- Perform Bear / Base / Bull scenario analysis
- Estimate intrinsic value using DCF
- Present financial insights clearly

---

## 📈 Key Financial Highlights

| Metric | FY2021 | FY2026 |
|---|---:|---:|
| Revenue | ₹420 Cr | ₹780 Cr |
| EBITDA | ₹65 Cr | ₹150 Cr |
| Net Profit | ₹35 Cr | ₹85 Cr |
| EBITDA Margin | 15.5% | 19.2% |
| Debt / Equity | 0.87x | 0.61x |
| Free Cash Flow | ₹37 Cr | ₹89 Cr |

### Key Observations

- Revenue increased from **₹420 Cr to ₹780 Cr**
- EBITDA increased from **₹65 Cr to ₹150 Cr**
- EBITDA margin improved from **15.5% to 19.2%**
- Debt / Equity declined from **0.87x to 0.61x**
- Free Cash Flow increased from **₹37 Cr to ₹89 Cr**

These trends indicate improving operating profitability, stronger cash generation, and lower financial leverage.

---

## 🔮 Financial Forecast

The base-case forecast projects the company to reach approximately:

- **FY2029 Revenue:** ₹1,010 Cr
- **FY2029 EBITDA:** ₹211 Cr
- **FY2029 Net Profit:** ₹130 Cr

The model also includes **Bear, Base and Bull scenarios** to evaluate how changes in assumptions can affect the company's financial performance and valuation.

---

## 💰 DCF Valuation

A **Discounted Cash Flow (DCF)** model was developed to estimate the company's intrinsic value.

### Key Assumptions

- **WACC:** 11.0%
- **Terminal Growth Rate:** 3.0%
- **Enterprise Value:** ₹1,282 Cr
- **Equity Value:** ₹1,064 Cr
- **Base-Case Implied Value:** ₹79.8/share

The valuation is an illustrative modelling exercise and should not be considered investment advice.
